## 🚀 Getting Started

### 1. Navigate to Project Directory
```bash
cd "/Users/anup.kanere/Desktop/New project/srbuildtec-website"
```

### 2. Start Development Server
```bash
npm run dev
```
Then open http://localhost:3000 in your browser

### 3. Build for Production
```bash
npm run build
```

### 4. Start Production Server
```bash
npm start
```

## 📝 Customization Guide

### Update Company Information
Edit `/data/company.json`:
- Company details
- Contact information (phone, email, address)
- Social media links
- Mission & vision
- Statistics

### Manage Services
Edit `/data/services.json`:
- Add/remove services
- Update descriptions
- Change service features

### Showcase Projects
Edit `/data/projects.json`:
- Add new projects
- Update project details
- Change categories and status
- Add real project images to `/public/projects/`

### Client Testimonials
Edit `/data/testimonials.json`:
- Add client reviews
- Update ratings and feedback

## 🌐 Deployment

### Option 1: Vercel (Recommended)
1. Push code to GitHub
2. Visit [vercel.com](https://vercel.com)
3. Import your repository
4. Click Deploy

### Option 2: Netlify
1. Run `npm run build`
2. Upload `.next` folder to Netlify

### Option 3: Any Node.js Hosting
- Build: `npm run build`
- Start: `npm start`
- Requires Node.js 18+
